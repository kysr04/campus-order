# 一杯 · 校园奶茶点单

一个纯前端的校园奶茶点单网站，按手机竖屏设计，也可以在 iPad 上演示；电脑上自动变成「左菜单 + 右购物车」两栏。

> 课程上机作业。饮品、价格、取餐号均为虚构，不构成真实交易。

---

## 一、怎么打开

### 1. 电脑上（最简单）

双击 `index.html`，用 Chrome / Edge 打开，所有功能都能用。

### 2. 手机上 / iPad 上演示（同一个网络）

双击项目里的 **`phone-preview.bat`**（电脑上需要装 Python 3）：

1. 窗口里会自动启动本地服务器，并打印几个地址；
2. 手机浏览器里输入**标着「推荐」**的那个地址，例如 `http://10.12.96.55/`；
3. 手机一连上，电脑窗口里会立刻出现 `[访问] ...` 的记录 —— 看到这一行就说明通了。

> **手机和电脑必须能互相访问。**
> 这台电脑只有一块有线网卡（校园网 `10.12.96.55`），没有 Wi-Fi；
> 手机一般连的是校园 Wi-Fi，而校园网通常会把有线和无线的设备互相隔开，
> 所以手机直接访问这个地址很可能会「连接超时」，这是网络问题，不是网页坏了。
>
> 最稳的办法是用 USB 数据线让两台设备点对点直连：
>
> 1. 手机用数据线插到电脑上；
> 2. 手机「设置」里打开 **USB 网络共享**（有的手机叫「USB 共享网络」）；
> 3. 电脑会多出一个网络，重新双击 `phone-preview.bat`；
> 4. 手机浏览器打开窗口里新出现的那个地址（一般是 `http://192.168.42.x/` 这种）。

### 3. 手机上打开（公网，用流量也行）

双击 **`公网预览.bat`**：它会开本地服务器，再用 ssh 隧道把网站挂到公网，
窗口里会打印一个这样的地址：

```
https://xxxxxxxx.lhr.life
```

手机（流量 / 任意 Wi-Fi 都行）直接打开这个地址就能用。

- 这个地址**只在窗口开着的时候有效**，关掉窗口就失效，下次启动会换一个新的；
- 第一次建立隧道要等 3~10 秒；
- 想让地址固定下来，见下面「八、已知限制」里的说明。

### 4. 打不开时怎么查

| 现象 | 原因 / 处理 |
| --- | --- |
| 电脑上双击 `index.html` 正常，手机上打不开 | 没启动服务器，或手机和电脑不在同一个网络；先双击 `phone-preview.bat`，或者直接用 `公网预览.bat` |
| 手机显示「连接超时 / 无法访问此网站」 | 网络把两台设备隔离了，改用 **USB 网络共享**，或直接 `公网预览.bat` |
| 手机显示「拒绝连接」 | 服务器没在跑：`phone-preview.bat` 的黑窗口被关掉了 |
| `phone-preview.bat` 窗口一闪就没了 | 电脑没装 Python 3，或安装时没勾选 `Add python.exe to PATH` |
| `公网预览.bat` 提示隧道没建起来 | 网络连不上 `localhost.run`（校园网偶尔会拦 ssh），换个网络再试，或先用局域网方式演示 |
| 手机能看首页，但点「去结算」购物车是空的 | 是在手机上直接打开了本地 `index.html`（file://）。改用两个 bat 走 `http://` / `https://` 就正常 |

> 另外 `screenshots/手机访问二维码.png` 是 2026-10-21 生成的旧二维码，
> 里面的地址和端口可能已经变了，以窗口里打印出来的地址为准。

## 二、三十秒演示流程

1. 首页点「招牌珍珠奶茶」旁边的 **＋**，底部购物车金额立刻变化；
2. 再点两次同一款，看它合并成「×3」；
3. 点进「芋泥波波奶茶」，选 **大杯**、**少冰**、**三分糖**、加 **珍珠**，底部价格实时变成新价格；
4. 加入购物车 → 点右上角购物车 → 数量加减、写备注；
5. 看「满 20 减 3」自动生效 → 提交订单；
6. 屏幕给出取餐号（如 **A10**）和预计等待时间 → 「我的订单」里能看到这一单。

## 三、目录结构

```
campus-order/
├── index.html        点单首页：分类、饮品卡片、购物车入口
├── detail.html       饮品详情：杯型 / 冰量 / 甜度 / 加料
├── cart.html         购物车：数量、删除、备注、满减、提交
├── order.html        下单成功：取餐号、等待时间、明细
├── history.html      我的订单：本机历史订单
├── about.html        关于本站：设计目的、技术说明、考核点对照
├── css/style.css     全站样式（移动端优先 + 桌面两栏）
├── js/data.js        分类、规格、加料、14 款饮品
├── js/app.js         购物车模型、价格计算、各页面渲染
├── phone-preview.bat 双击 → 本地服务器，同一网络的手机可访问（演示用）
├── 公网预览.bat      双击 → 本地服务器 + 公网隧道，手机用流量也能打开（演示用）
├── tools/preview.py  两个 bat 共用的服务器脚本（不用改，也不用交）
├── screenshots/      手机 / iPad / 电脑 页面截图
├── PLAN.md           实施计划
└── README.md         本文件
```

## 四、规则与价格

| 项目 | 规则 |
| --- | --- |
| 杯型 | 中杯 +0，大杯 +3 |
| 冰量 | 正常冰 / 少冰 / 去冰 / 热饮 |
| 甜度 | 全糖 / 七分糖 / 五分糖 / 三分糖 / 无糖 |
| 加料 | 珍珠 +3、椰果 +3、芋泥 +5、奶盖 +6、布丁 +4（可多选） |
| 优惠 | 商品金额满 20 元减 3 元 |
| 合计 | 单价 = 基础价 + 杯型 + 加料；合计 = 小计 − 满减 |

## 五、用到的技术

- **HTML5**：6 个页面共用同一套页头、优惠条与页脚。
- **CSS3**：设计变量统一配色；Grid 卡片网格；渐变饮品封面；移动端底部结算条；
  宽屏自动切换两栏；`env(safe-area-inset-bottom)` 适配刘海屏。
- **原生 JavaScript（ES6）**：
  - **购物车行唯一键**：饮品编号 + 杯型 + 冰量 + 糖度 + 排序后的加料，
    规格相同才合并数量；
  - **实时算价**：每次选规格或加料都立即重算单价；
  - **满减**：小计 ≥ 20 时自动减 3；
  - **本地存储**：购物车 `yd_cart`、历史订单 `yd_orders`、最近一单 `yd_last_order`；
  - **取餐号**：按下单序号生成 `A10` 这类号码，并估算等待时间。
- **演示辅助**：`tools/preview.py` 只负责开本地 HTTP 服务、需要时开一条 ssh 公网隧道，
  让手机也能打开这个网站，不属于网站本身的技术实现。

## 七、想改哪儿，看这里

- **改菜单**：编辑 `js/data.js` 里的 `DRINKS`，价格填中杯基础价。
- **改加料价**：改 `ADDONS` 里的 `price`。
- **改满减**：改 `js/data.js` 顶部的 `DISCOUNT`（门槛与金额）。
- **改配色**：改 `css/style.css` 开头的 `--brand`、`--brand-2`、`--bg`。
- **改店名**：全局搜索「一杯」替换即可。

## 八、已知限制

- 没有后端：菜单写在前端文件里，购物车和订单存在浏览器 localStorage，换设备就看不到。
- 取餐号是按本机订单数推算的模拟号码，不对接真实叫号系统。
- 没有支付功能，提交订单即视为演示完成。
- 饮品图使用渐变 + emoji，不依赖任何外部图片。
- 局域网预览要求手机和电脑能互相访问：同一局域网、或 USB 网络共享；校园网隔离时手机访问不到。
- **公网地址是临时的**：`公网预览.bat` 每次启动会拿到一个新的 `*.lhr.life` 地址，
  且需要电脑开着、窗口不关。想要一个永久的固定网址，可以把这 6 个 html + css + js
  上传到 GitHub Pages / Gitee Pages / Cloudflare Pages 这类静态托管（纯前端项目，直接传就行）。
